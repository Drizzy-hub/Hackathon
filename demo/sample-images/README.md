# Sample images

Place demonstration images in this directory using the filenames referenced in
`evaluation/test_cases.json`:

- `doc-01.jpg`, `doc-02.jpg`, `doc-03.jpg` — documents and notices.
- `obj-01.jpg`, `obj-02.jpg`, `obj-03.jpg` — everyday objects.
- `scene-01.jpg`, `scene-02.jpg`, `scene-03.jpg` — people and scenes.
- `prod-01.jpg`, `prod-02.jpg`, `prod-03.jpg` — products and menus.

Guidance:

- Prefer real printed notices, menus and product labels over stock photography.
- Avoid medicine labels, emergency signage and navigation-critical scenes.
- Pretest each image before the demo and keep the expected answers ready.
- If a dynamically-generated Yoruba audio is not sufficiently intelligible for an image, prepare
  a clearly-disclosed, native-speaker-reviewed recorded fallback.
